# 表达删改案例

| 当前任务与事实 | 待删改表达 | 改后内容或处理 |
| --- | --- | --- |
| 用户询问显示故障是否修好；画面已经恢复，相关检查通过。 | 目前能正常显示，但不代表关闭显示器时也能作出相同判定。 | 显示已恢复正常，相关检查通过。 |
| 用户询问事实能否在重启后保留；已确认写入的事实会持久保存。 | 已写入的事实会保留；未写入的无法恢复，断电和不可靠的网络文件系统不在保证内。 | 成功写入的事实在重启后仍会保留。 |
| 用户询问如何配置目录访问。 | 服务账户需要读写权限；看不到的映射盘、未授权共享和未挂载目录都不能访问。 | 为服务账户授予目标目录的读写权限。 |
| 正在写首次安装的快速开始。 | 已有配置冲突时停止；重复迁移不会覆盖修改；旧密码摘要需要先转换。 | 删除旧版本迁移细节，直接写首次安装步骤。 |
| 正在介绍记忆检索功能。 | 后台维护任务及其后代不计入费用、调用次数和任务耗时，也不进入用户 agent 列表。 | 删除这段计费与列表说明。 |
| 用户要整理会议纪要；记录确定上线日期为 5 月 8 日、负责人为陈敏。 | 会上未讨论融资、招聘和品牌，因此不作判断。 | 上线日期为 5 月 8 日，负责人为陈敏。 |
| 用户要选型建议；已给出单机、低写入量、希望免运维的条件。 | 没有绝对好坏，各有优劣，需要综合考虑。 | 优先选 SQLite，适合当前单机、低写入量和免运维的要求。 |
| 修改已完成，约定的检查全部通过。 | 已完成，但仍需进一步验证，不能保证所有环境都正常。 | 已完成，相关检查通过。 |
| 测试命令因缺少 pytest 启动失败。 | 各种环境因素都可能影响验证，建议进一步检查。 | 测试因缺少 pytest 启动失败。 |
| 用户问函数是否有副作用；函数调用了文件删除操作。 | 你可能以为它只是读取数据，但这种理解是片面的。 | 有副作用：函数会删除文件。 |
